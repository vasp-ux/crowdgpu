# Research

GPU scheduling research, profiling experiments, interference studies, datasets, and
Jupyter notebooks.

## Directory Layout

```
research/
├── scheduling/     # Scheduling algorithm implementations and evaluations
├── profiling/      # GPU workload profiling data and scripts
├── interference/   # Resource interference measurement experiments
├── experiments/    # Documented experiment runs
├── datasets/       # Research datasets (large files excluded via .gitignore)
└── notebooks/      # Jupyter notebooks
```

This directory is for research and experimentation, not production code.
Code promoted to production should move to the appropriate `apps/` directory.
